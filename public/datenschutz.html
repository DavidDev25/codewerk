2. Überblick

Codewerk ist eine kostenlose Lernplattform für JavaScript. Sie können Codewerk ohne Konto nutzen. Für das Speichern im Konto und den KI-Tutor ist eine Anmeldung mit GitHub nötig. Codewerk setzt keine Analyse- oder Tracking-Dienste ein und lädt keine Inhalte von fremden Servern: Editor und Schriftarten liegen auf meinem eigenen Server.

Beim Aufruf der Seite verarbeitet der Server automatisch Informationen, die Ihr Browser übermittelt: IP-Adresse, Datum und Uhrzeit des Zugriffs, aufgerufene Seite, Referrer-URL, Browsertyp und Betriebssystem.

4. Nutzung ohne Konto

Ohne Anmeldung werden Ihr Lernfortschritt (Code, erledigte Lektionen) und Ihre Einstellungen (Farben, Textgröße, ob Sie die Einführungstour gesehen haben) nur im Local Storage Ihres Browsers gespeichert. Diese Daten verlassen Ihr Gerät nicht. Die Speicherung ist für die von Ihnen genutzten Funktionen unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG). Sie können sie jederzeit über die Einstellungen Ihres Browsers löschen.
