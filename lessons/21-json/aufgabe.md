## Aufgabe: Einstellungen merken

Das Objekt `einstellungen` gibt es schon.

1. `const gespeichert` ist `einstellungen` als JSON-Text.
2. `const geladen` ist das Objekt, das du aus `gespeichert` zurückgewinnst.
3. `const huebsch` ist `einstellungen` als JSON-Text mit **2** Leerzeichen Einrückung.
4. `laden(text)` gibt das Objekt aus dem JSON-Text zurück. Ist `text` `null` oder ein leerer Text, gibt sie `{ thema: "hell", schrift: 16 }` zurück.
