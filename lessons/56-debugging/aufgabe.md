## Aufgabe: Vier versteckte Fehler

Im Editor steht Code von jemand anderem. Jede der vier Funktionen hat **genau einen** Fehler. Finde und repariere ihn, ohne die Funktion neu zu schreiben.

1. `durchschnitt(zahlen)` soll den Durchschnitt liefern, gibt aber `NaN` zurück.
2. `istGleich(a, b)` soll nur bei gleichem Wert **und** Typ `true` liefern.
3. `sortiertKopie(liste)` soll eine sortierte Kopie liefern, ändert aber das Original.
4. `letzter(liste)` soll das letzte Element liefern.

Nutze `console.log`, um Zwischenwerte zu sehen, und lies genau, welche Tests scheitern.
