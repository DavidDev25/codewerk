## Aufgabe: Die Umfrage

Das Array `antworten` gibt es schon.

1. `const optionen` ist ein Array, in dem jede Antwort nur **einmal** vorkommt (in der Reihenfolge des ersten Auftretens).
2. `zaehlen(liste)` gibt eine **Map** zurück, die für jeden Eintrag zählt, wie oft er vorkommt.
3. `const ergebnis` ist das Ergebnis von `zaehlen(antworten)`.
4. `beliebteste(liste)` gibt den Eintrag zurück, der am häufigsten vorkommt. Nutze dafür `zaehlen`.
