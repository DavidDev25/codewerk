## Willkommen bei Codewerk

:::alltag
Codewerk ist wie eine Fahrschule mit Übungsplatz. Erst erklärt dir jemand kurz, worum es geht. Dann fährst du selbst. Und am Ende sagt dir der Prüfer genau, was schon klappt und was noch nicht.
:::

Jede Lektion läuft in vier Schritten ab:

1. **Verstehen:** Du liest hier eine kurze Erklärung mit Beispielen.
2. **Aufgabe:** Im Reiter daneben steht, was dein Code können soll.
3. **Code schreiben:** Du schreibst im Editor und drückst **Ausführen** (oder `Strg + Enter`).
4. **Prüfen:** Automatische Tests zeigen dir mit ✓ und ✗, was schon stimmt.

Beispiele wie dieses kannst du direkt mit **Ausprobieren** starten:

```js
console.log("Hallo Codewerk!");
console.log(2 + 3);
```

`console.log(…)` zeigt einen Wert unter **Ausgabe** an. Das brauchst du in fast jeder Lektion.

Unter dem Editor gibt es drei Bereiche:

- **Prüfung:** Welche Tests bestehen. Bei einem roten Test steht ein Hinweis dabei.
- **Ausgabe:** Alles, was `console.log` ausgibt, und Fehlermeldungen in einfachen Worten.
- **Diagramm:** Ein Bild deiner Variablen. So siehst du, was dein Code im Speicher anlegt.

Wenn du hängst:

- **Tipp anzeigen** im Reiter Aufgabe gibt dir einen kleinen Anstoß.
- Der **Tutor** ist eine KI, die dir Hinweise gibt und Fragen stellt. Die Lösung verrät er nicht, denn du sollst es verstehen, nicht kopieren.

Dein Code wird automatisch gespeichert. Die Tour durch die Oberfläche startest du jederzeit über **Tour** oben rechts.
