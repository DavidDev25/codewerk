## Aufgabe: Dein erster Lauf

Hier probierst du einmal den ganzen Ablauf aus. Du änderst zwei Zeilen, drückst **Ausführen** und schaust, ob alles grün wird.

### Schritt 1: Die Ausgabe ändern

Im Editor steht `console.log("Ändere mich");`. Am Ende soll unter **Ausgabe** das hier stehen:

```
Hallo Codewerk!
```

Ändere dafür nur den Text zwischen den Anführungszeichen. Das Ausrufezeichen gehört dazu.

### Schritt 2: Deine Lieblingszahl

Die letzte Zeile beginnt mit `//`. Damit ist sie ausgeschaltet. So gehst du vor:

1. Lösche die zwei Schrägstriche `//` am Anfang der Zeile.
2. Schreib hinter das `=` eine Zahl, zum Beispiel `7`.

```js
const lieblingszahl = 7;
```

Wichtig: Die Zahl steht **ohne** Anführungszeichen. Mit Anführungszeichen wäre sie ein Text.

### Schritt 3: Prüfen

Drücke **Ausführen**. Unter **Prüfung** sollten jetzt beide Tests grün sein. Öffne danach den Reiter **Diagramm**. Dort siehst du deine `lieblingszahl` als kleine Box.
