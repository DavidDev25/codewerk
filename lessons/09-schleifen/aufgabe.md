## Aufgabe: Fünf Schleifen-Funktionen

1. `summe(zahlen)` gibt die Summe aller Zahlen im Array zurück. `summe([1, 2, 3])` ergibt `6`.
2. `nurGrosse(zahlen)` gibt ein neues Array zurück, das nur die Zahlen **über 10** enthält.
3. `einsBis(n)` gibt ein Array von `1` bis `n` zurück. `einsBis(3)` ergibt `[1, 2, 3]`.
4. `ersteNegative(zahlen)` gibt die **erste** negative Zahl zurück und hört dann auf zu suchen. Gibt es keine, `null`.
5. `verdoppelnBis(start, grenze)` verdoppelt `start` so lange, bis der Wert **mindestens** `grenze` erreicht, und gibt zurück, wie oft verdoppelt wurde. Nutze `while`. `verdoppelnBis(1, 100)` ergibt `7` (1 → 2 → 4 → … → 128).
